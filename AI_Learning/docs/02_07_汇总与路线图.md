## 二、关键认知总结

### 2.1 Agent 的本质

```
Agent ≠ 模型 × 工具

Agent = 模型 (大脑)
      + 核心循环 (心跳)
      + 工具系统 (手脚)
      + 记忆系统 (经验)
      + 权限系统 (安全阀)
      + 上下文管理 (注意力)
```

### 2.2 开发 Agent 的核心挑战

| 挑战 | Claude Code 的做法 | 自建时的建议 |
|------|-------------------|-------------|
| 模型选型 | 自家 Claude 4.x | 多 Provider 抽象层 |
| 工具接入 | MCP 协议 | 优先 MCP，兼容 Function Calling |
| 上下文超限 | 四层压缩 | 至少两层（自动+手动） |
| 安全控制 | 四级权限 | 至少两级（默认 ask + bypass 选项） |
| 长任务保持专注 | 记忆 + CLAUDE.md | 至少需要记忆系统 |
| 流式反馈 | AsyncGenerator | 生成器模式是最佳实践 |

### 2.3 和传统软件开发的区别

| 传统软件 | Agent 开发 |
|---------|-----------|
| 需求确定 → 写代码 → 测试 | Prompt 迭代 → 工具调优 → 评估 |
| Bug = 代码写错了 | Bug = Prompt 没说清楚 / 工具没提供 |
| 测试：assert 预期输出 | 测试：评估任务完成率 |
| 部署即完成 | 部署只是开始，需要持续观察和调优 |

## 三、自建 Agent 决策指南

### 第一步：明确场景

```
你的 Agent 要做的事
  ├─ 编码 (代码生成/编辑/审查)
  │   → 推荐: TypeScript + Anthropic SDK + MCP + CLI/IDE
  │
  ├─ 数据分析 (SQL 查询/报表生成)
  │   → 推荐: Python + LangChain + 数据库工具 + Web UI
  │
  ├─ 客服/问答 (产品咨询/工单处理)
  │   → 推荐: Python + Dify/Coze + RAG + 多平台发布
  │
  ├─ 工作流自动化 (审批/通知/数据同步)
  │   → 推荐: n8n/Temporal + API 工具 + Webhook
  │
  └─ 通用助手 (什么都做)
      → 推荐: 从编码 Agent 起步，逐步扩展
```

### 第二步：选技术栈

```
快速原型 (1 天出效果):
  Python + OpenAI Agents SDK + Streamlit

小团队产品 (1-2 周 MVP):
  TypeScript + Vercel AI SDK + Next.js + MCP

企业级平台 (1-2 月):
  TypeScript(Python) + LangGraph + PostgreSQL + Docker + 完整监控
```

### 第三步：定发布形态

```
目标用户决定形态:
  开发者用户    → CLI npm 包 或 VS Code 插件
  非技术用户    → Web 应用 或 聊天界面
  其他系统调用  → REST API / gRPC 服务
```

## 四、推荐学习路线

### 如果你准备自建 Agent

```
Week 1: 通读 02_01 ~ 02_07，建立全局认知
Week 2: 用 Claude Code Agent 模式理解源码 (参考 01_01~01_09)
Week 3: 选一个简单场景，写 MVP (参考 02_06 Phase 2)
Week 4-6: 迭代，逐步加入权限/记忆/压缩
Week 7+: 服务化/产品化
```

### 学习项目建议

```
Level 1: 写一个"问答机器人"
  - 调用 API，一问一答，无工具
  - 目标: 理解 API 调用和流式处理

Level 2: 加上工具执行
  - 让 Agent 能读文件、执行命令
  - 目标: 理解 Agent Loop

Level 3: 加上记忆和权限
  - 记忆用户偏好，危险操作需确认
  - 目标: 理解安全和持久化

Level 4: 多 Agent 协作
  - 多个 Agent 协同完成复杂任务
  - 目标: 理解编排和通信
```

## 五、核心结论

```
1. Agent 不是新技术，而是 LLM + 工程能力的组合
   → 模型能力决定下限，工程设计决定上限

2. 不要一开始就做大而全
   → 先做垂直领域的最小闭环（一个场景、三个工具、能跑通）

3. 模型不是你的壁垒
   → 你随时可以换模型，但工具生态和产品体验才是壁垒

4. Claude Code 是很好的学习样本
   → 它的 Agent Loop / 工具系统 / 权限模型 / 记忆系统 都是工业级参考

5. 动手最重要
   → 读完这些文档，选一个具体场景，开始写代码
```
