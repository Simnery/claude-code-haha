## 一、模型选择优先级链

`src/utils/model/model.ts:87-96` 定义了明确的优先级：

```
1. 会话中 /model 命令切换        (mainLoopModelOverride)
2. 启动参数 --model <name>       (CLI flag)
3. ANTHROPIC_MODEL 环境变量       (.env 配置)
4. settings.json 用户设置         (持久化配置)
5. 内置默认值                     (Opus for Max/Team, Sonnet for others)
```

### 核心函数

| 函数 | 位置 | 作用 |
|------|------|------|
| `getUserSpecifiedModelSetting()` | L66 | 读取 modelOverride → ANTHROPIC_MODEL → settings |
| `getMainLoopModel()` | L97 | 调用 `getUserSpecifiedModelSetting()` + `parseUserSpecifiedModel()` |
| `getDefaultMainLoopModelSetting()` | L192 | Opus for Max/Team Premium, Sonnet for all others |
| `getDefaultOpusModel()` | L110 | `ANTHROPIC_DEFAULT_OPUS_MODEL` env 或 `claude-opus-4-7` |
| `getDefaultSonnetModel()` | L127 | `ANTHROPIC_DEFAULT_SONNET_MODEL` env 或 `claude-sonnet-4-6` |
| `getDefaultHaikuModel()` | L142 | `ANTHROPIC_DEFAULT_HAIKU_MODEL` env 或 `claude-haiku-4-5` |
| `getSmallFastModel()` | L41 | `ANTHROPIC_SMALL_FAST_MODEL` env 或 `getDefaultHaikuModel()` |
| `parseUserSpecifiedModel()` | L477 | 别名 → 具体模型 ID 的最终解析 |
| `getRuntimeMainLoopModel()` | L162 | 运行时模型解析，处理 200K 超限降级 |

### 200K 超限降级 (L162-175)
当权限模式为 `plan` 且最后一条 assistant 消息超过 200K tokens 时，自动降级到不带 `[1m]` 的模型变体，避免上下文溢出。

## 二、模型别名系统 (`src/utils/model/aliases.ts`)

```
MODEL_ALIASES = ['sonnet', 'opus', 'haiku', 'best', 'sonnet[1m]', 'opus[1m]', 'opusplan']
MODEL_FAMILY_ALIASES = ['sonnet', 'opus', 'haiku']
```

### 别名解析
- `sonnet` → `claude-sonnet-4-6` (或对应第三方模型)
- `opus` → `claude-opus-4-7`
- `haiku` → `claude-haiku-4-5`
- `best` → 解析为默认 Opus 模型
- `sonnet[1m]` → 1M 上下文版的 Sonnet
- `opus[1m]` → 1M 上下文版的 Opus
- 非别名 (如 `deepseek-chat`, `MiniMax-M2.7`) → **原样透传**

## 五、上下文窗口 (`src/utils/model/modelContextWindows.ts`)

### 内置上下文窗口表 (`DIRECT_MODEL_CONTEXT_WINDOWS`)

| 模型 | 上下文 |
|------|--------|
| `claude-opus-4-7` | 1,000,000 |
| `claude-sonnet-4-6` | 200,000 |
| `claude-haiku-4-5` | 200,000 |
| `deepseek-v4-pro` | 1,000,000 |
| `deepseek-chat` | 1,000,000 |
| `deepseek-reasoner` | 1,000,000 |
| `kimi-k2.6` | 262,144 |
| `minimax-m2.7` | 204,800 |
| `glm-5.1` | 200,000 |
| `qwen3.5-plus/flash` | 1,000,000 |
| ... | ... |

### 正则匹配 (`PATTERN_MODEL_CONTEXT_WINDOWS`)
对不在精确表中的模型，用正则匹配：
- `/^anthropic\/claude-opus-4\.7\b/i` → 1M
- `/^openai\/gpt-4\.1\b/i` → 1,047,576
- `/^google\/gemini-(?:2\.0|2\.5|3)/i` → 1,048,576

### 环境变量覆盖
用户可通过 `CLAUDE_CODE_MODEL_CONTEXT_WINDOWS='{"model-name": 200000}'` 自定义上下文窗口。

### 解析优先级
```
1. CLAUDE_CODE_MODEL_CONTEXT_WINDOWS 环境变量
2. DIRECT_MODEL_CONTEXT_WINDOWS 精确匹配
3. PATTERN_MODEL_CONTEXT_WINDOWS 正则匹配
4. undefined (无限制)
```

## 六、模型选项与选择器 (`src/utils/model/modelOptions.ts`)

### `getModelOptions()`
构建 `/model` 命令弹出的模型选择器列表：
- 读取 `ANTHROPIC_CUSTOM_MODEL_OPTION` 自定义选项
- 读取 `additionalModelOptionsCache` 额外选项
- 区分 1M 上下文版本与标准版本
- 附带定价信息 (仅 1P 用户)

### 关键 model option 函数
- `getOpus46_1MOption()` → Opus 1M 上下文选项
- `getSonnet46_1MOption()` → Sonnet 1M 上下文选项
- `getMaxSonnet46_1MOption()` → Max 用户 Sonnet 1M 选项

## 七、模型允许列表 (`src/utils/model/modelAllowlist.ts`)

### `isModelAllowed(model)` (L100)
检查模型是否在 `availableModels` 允许列表中：
- 支持 family alias 匹配: `"opus"` 匹配所有 Opus 版本
- 支持版本前缀匹配: `"opus-4-5"` 匹配 `claude-opus-4-5-*`
- 支持完整模型 ID 匹配

## 八、模型能力检测

### 思考能力 (Thinking)
- `shouldEnableThinkingByDefault()` — 默认是否启用思考
- `modelSupportsThinking()` — 模型是否支持思考模式
- `CLAUDE_CODE_DISABLE_THINKING` — 环境变量禁用

### Effort 值
- `getInitialEffortSetting()` — 初始 effort 设置
- `parseEffortValue()` — 解析 effort 值 (low/medium/high)

### 模型支持覆盖 (`src/utils/model/modelSupportOverrides.ts`)
通过环境变量 `ANTHROPIC_DEFAULT_*_MODEL_SUPPORTED_CAPABILITIES` 为第三方模型声明能力：
- `thinking` — 支持思考
- `effort` — 支持 effort
- `adaptive_thinking` — 支持自适应思考
