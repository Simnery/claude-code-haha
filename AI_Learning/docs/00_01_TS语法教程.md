## 一、前置说明：和 C 语言的核心差异

在进入具体语法之前，先建立几个关键认知：

| C 语言 | TS/JS | 影响 |
|--------|-------|------|
| 需要编译（gcc → a.out） | 直接运行（bun run xxx.ts） | 改完代码立刻跑，开发节奏更快 |
| 手动管理内存（malloc/free） | 自动垃圾回收（GC） | 不用担心内存泄漏，但不可控 GC 时机 |
| 静态类型（int x） | 动态类型（let x = 1） + 可选静态类型标注 | 可以写类型也可以不写（但本项目全部写了） |
| 阻塞 I/O（read 卡住等） | 非阻塞 I/O（async/await） | 必须理解异步模型（见 2.14 节） |
| 指针（int* p） | 对象引用（无指针语法） | 不需要 `*` `&` `->` 这些符号 |
| `#include "xxx.h"` | `import ... from './xxx'` | 模块化更自然 |

## 二、关键字 (Keywords)

TS/JS 保留了以下关键字，不能用作变量名：

### 2.1 和 C 一样的
```
if    else    switch    case    default
for   while   do       break   continue
return
```

### 2.2 和 C 不同/特有的

| 类别 | 关键字 | 说明 |
|------|--------|------|
| 变量声明 | `let`, `const`, `var` | C 没有（C 直接 `int x`），JS 必须用关键字声明 |
| 函数 | `function`, `yield`, `async`, `await` | `yield/async/await` 是 C 没有的新概念 |
| 模块 | `import`, `export`, `from` | 替代 C 的 `#include` |
| 错误 | `try`, `catch`, `finally`, `throw` | C 没有异常机制 |
| 空值 | `null`, `undefined` | C 只有 `NULL`，JS 有两个不同的"空" |
| 类型 | `typeof`, `instanceof`, `as` | 运行时/编译时判断类型 |
| OOP | `class`, `extends`, `implements`, `new`, `this`, `super` | C 没有 class（只有 struct） |
| 布尔 | `true`, `false` | ⚠️ 小写！不是 C 的 `TRUE`/`FALSE` |

## 三、基本数据类型 (Basic Types)

```typescript
// ===== 和 C 一样的概念 =====
let age: number = 30            // C: int age = 30
let price: number = 9.99        // C: float price = 9.99（TS 不区分 int/float，统一叫 number）
let name: string = "Claude"     // C: char* name = "Claude"
let isDone: boolean = false     // C: int isDone = 0（JS 有真正的 boolean）

// ===== C 没有的类型 =====
let nothing: null = null        // 故意设为空
let notSet: undefined = undefined  // 还没赋值
let anything: any = "hello"     // 任意类型，关闭类型检查（尽量少用）
let unsure: unknown = 42        // 未知类型，比 any 安全（使用前必须检查类型）

// ===== TS 独有：字面量类型 =====
let direction: "left" | "right" = "left"   // 只能是这两个字符串之一
let status: 0 | 1 | 2 = 0                  // 只能是这三个数字之一
```

> **为什么 C 有 int/float/double/short/long/char，TS 只有 number？**
>
> C 要精确控制内存（int=4 字节，double=8 字节）。TS 是高层语言，`number` 统一用 64 位浮点数，整数在 ±2^53 范围内精确。日常开发不需要操心底层字节数。


## 五、运算符 (Operators)

### 5.1 和 C 完全一样的

| 类别 | 运算符 |
|------|--------|
| 算术 | `+` `-` `*` `/` `%` `++` `--` |
| 赋值 | `=` `+=` `-=` `*=` `/=` `%=` |
| 比较 | `<` `>` `<=` `>=` |
| 逻辑 | `&&` `||` `!` |
| 位运算 | `&` `|` `^` `~` `<<` `>>` `>>>` |

### 5.2 和 C 不同的

```typescript
// ⚠️ 相等比较：用三个等号！不是 C 的两个等号
a === b    // 严格相等（值和类型都相等，推荐！）
a !== b    // 严格不等
a == b     // 松散相等（自动类型转换，有坑，别用）

// 举例为什么 == 有坑：
0 == "0"    // true  ← 自动类型转换，混淆视听
0 === "0"   // false ← 类型不同，直接判错，合理
```

### 5.3 C 没有的运算符

```typescript
a ?? b         // 空值合并：a 是 null/undefined 时取 b
a?.b           // 可选链：a 是 null/undefined 时不报错，直接返回 undefined
a ? b : c      // 三元运算符（C 也有，写在这里提醒）
...arr         // 展开运算符：把数组/对象"拆开"
=> {}           // 箭头函数（读作"转到"）：(x) => x*2 意思是"接收 x，返回 x*2"
```

## 六、控制流 — 条件分支

```typescript
if (score >= 90) {

  case "blue":
    console.log("蓝色")

}

// ===== 三元表达式（和 C 完全一样）=====
const label = isActive ? "激活" : "未激活"
//            条件      真→     假→
```

## 七、控制流 — 循环

### 7.1 和 C 一样的

```typescript
// for 循环
for (let i = 0; i < 10; i++) {
  console.log(i)    // 输出 0 到 9
}
// while 循环
let i = 0
while (i < 10) { console.log(i); i++ }
// do...while
let j = 0
do { console.log(j); j++ } while (j < 10)
// break / continue 用法完全一样
```

### 7.2 TS 独有的 for-of：遍历数组元素

```typescript
const fruits = ["苹果", "香蕉", "橘子"]

// for-of：逐个取出数组元素（比 for(;;) 更简洁，不容易写错下标）
for (const fruit of fruits) {
  console.log(fruit)    // 依次输出：苹果, 香蕉, 橘子
}
```

### 7.3 forEach 方法

```typescript
// forEach 是数组自带的方法，"对每个元素执行某个操作"
fruits.forEach(fruit => console.log(fruit))
// 拆解：
//   fruits            → 数组
//   .forEach( ... )   → 调用 forEach 方法
//   fruit => ...      → 箭头函数：每次拿一个元素，取名叫 fruit
//   console.log(fruit)→ 打印它
//
// 执行过程：
//   第 1 轮：fruit = "苹果" → console.log("苹果")
//   第 2 轮：fruit = "香蕉" → console.log("香蕉")
//   第 3 轮：fruit = "橘子" → console.log("橘子")
//
// forEach 不需要 break/continue（想中断用 for-of）
```

### 7.4 for-in：遍历对象的键名

```typescript
const user = { name: "小明", age: 18 }
for (const key in user) {
  console.log(key, user[key])   // name 小明, age 18
}
```

## 八、函数 (Functions)

### 8.1 普通函数

```typescript
function add(a: number, b: number): number {
  return a + b
}
// 拆解：
//   function   → 关键字，声明"这是一个函数"
//   add        → 函数名
//   (a, b)     → 参数列表：两个输入，都是 number 类型
//   : number   → 返回值类型（冒号后面）
//   { ... }    → 函数体

// 调用示例：
add(3, 5)      // 返回 8
add(100, 200)  // 返回 300

// 对比 C：
//   int add(int a, int b) { return a + b; }   ← C：类型在前
//   function add(a: number, b: number): number ← TS：类型在后（用冒号）
```

### 8.2 箭头函数（本项目大量使用）

```typescript
// 完整写法
const add = (a: number, b: number): number => {
  return a + b
}

// 函数体只有一行时可以省略 {} 和 return
const add = (a: number, b: number): number => a + b
//          ↑参数↑          ↑返回类型↑    ↑返回值（自动 return）↑

// 只有一个参数时可以省略括号
const double = (n: number): number => n * 2

// 无参数时必须写括号
const sayHi = (): void => console.log("Hi")

// void 表示"没有返回值"
```

### 8.3 可选参数和默认值

```typescript
// 可选参数：参数名后加 ?
function greet(name: string, title?: string): string {
  return title ? `${title} ${name}` : name
}
greet("小明")              // "小明"（title 没传，是 undefined）
greet("小明", "工程师")    // "工程师 小明"

// 拆解 return 这一行：
//   三元运算符：条件 ? 值A : 值B
//     title ? ... : name → title 有值走前面，没值走后面
//   模板字符串：`${变量} 文字`
//     `${title} ${name}` → 反引号 `` 包起来，${} 嵌入变量值
//     → "工程师 小明"（自动在中间加了空格）

// 默认参数值：直接 =
function multiply(a: number, b = 1): number {
  return a * b
}
multiply(5)     // 5（b 默认是 1）
multiply(5, 2)  // 10
```

### 8.4 剩余参数（类似 C 的 va_args）

```typescript
function sum(...nums: number[]): number {
  return nums.reduce((a, b) => a + b, 0)
}
sum(1, 2, 3, 4, 5)  // 15

// 拆解两个语法：
//
// ① 剩余参数 ...nums：
//    把多余的参数全部打包成一个数组
//    sum(1,2,3,4,5) → nums = [1, 2, 3, 4, 5]
//
// ② reduce：把数组"归约"成一个值
//    nums.reduce((a, b) => a + b, 0)
//      a = 上一轮的结果（首轮用初始值 0）
//      b = 当前元素
//    逐轮追踪：
//      第1轮: a=0,  b=1 → 1
//      第2轮: a=1,  b=2 → 3
//      第3轮: a=3,  b=3 → 6
//      第4轮: a=6,  b=4 → 10
//      第5轮: a=10, b=5 → 15
//
// 等价 for 循环写法：
//   let total = 0
//   for (const n of nums) total += n
//   return total
```

### 8.5 闭包（函数"记住"了外部变量）

```typescript
function makeCounter(): () => number {
  let count = 0
  return () => ++count    // 返回的函数"抓住"了 count
}
const counter = makeCounter()
counter()  // 1
counter()  // 2
counter()  // 3（count 没有被销毁！）

// 闭包原理：
//   makeCounter() 执行时创建了 count
//   返回的箭头函数"引用"了外部的 count
//   JS 引擎发现有人还在引用 count → 不会回收它
//   "闭包" = 函数 + 它记住的外部变量
//
// 对比 C：函数返回后局部变量就销毁了
//   要实现同样效果，C 得用 static 局部变量或全局变量
//
// 独立闭包：每次调用 makeCounter() 创建独立的 count
const c1 = makeCounter()
const c2 = makeCounter()
c1()  // 1
c1()  // 2
c2()  // 1 ← c2 的 count 从 0 开始，独立于 c1
```

## 九、对象 (Object)

> TS/JS 的对象类似 C 的 struct，但更灵活：属性可以动态增删，可以包含函数。

```typescript
// ===== 定义对象 =====
const user = {
  name: "小明",           // 属性
  age: 18,               // 属性
  scores: [90, 85, 92],  // 属性可以是数组
  greet() {              // 方法（函数作为属性）
    console.log(`你好，我叫${this.name}`)   // this 指当前对象
  }
}

// ===== 访问对象 =====
user.name       // "小明"（点语法，常用）
user["name"]    // "小明"（方括号语法）
user.greet()    // "你好，我叫小明"

// ===== TS interface：给对象加类型约束（类似 C 的 struct 定义）=====
interface User {
  name: string          // 必须有 name，类型是 string
  age: number           // 必须有 age，类型是 number
  email?: string        // 可选（有 ? 标记），可以不传
  readonly id: number   // 只读，创建后不能修改
}

const u: User = { name: "小明", age: 18, id: 1 }
// u.id = 2  ← 编译报错！只读属性不能改
```

## 十、数组 (Array)

> JS 的数组是动态的（自动扩容），不像 C 要指定 `int arr[10]`。

```typescript
// ===== 声明 =====
const nums: number[] = [1, 2, 3]
const names: string[] = ["A", "B"]
const mixed: (number | string)[] = [1, "hello"]  // 混合类型

// ===== 基本操作 =====
nums.push(4)      // 末尾加：[1,2,3,4]
nums.pop()        // 末尾删，返回 4
nums.unshift(0)   // 开头加：[0,1,2,3]
nums.length       // 长度：3
nums[0]           // 访问第 0 个：1（和 C 一样从 0 开始）

// ===== 常用遍历/转换方法 =====
nums.forEach(n => console.log(n))         // 逐个处理
const doubled = nums.map(n => n * 2)      // 逐个映射：[2,4,6]
const filtered = nums.filter(n => n > 1)  // 过滤：[2,3]
const found = nums.find(n => n === 2)     // 查找第一个匹配：2
const has = nums.includes(3)              // 包含判断：true
const sum = nums.reduce((a, b) => a + b, 0) // 归约求和：6
```

## 十五、异步编程 (Async Programming)

> **这是 JS/TS 和 C 最大的差异之一。** C 读文件 = 函数卡住等。JS 单线程，不能卡住整个程序。

### 15.1 演进过程

```typescript
// 第 0 层：回调（最原始，已淘汰）
readFile("data.txt", (error, data) => {
  if (error) throw error
  console.log(data)    // 只有读完文件才会执行到这里
})
// 函数不卡住，直接返回。文件读完后执行回调

// 第 1 层：Promise（代表一个"将来的值"）
const promise: Promise<string> = fetch("https://api.example.com")
  .then(response => response.text())
  .catch(error => console.error(error))

// 第 2 层：async/await（Promise 的语法糖，本项目主要使用）
async function loadUser(id: number): Promise<User> {
  const response = await fetch(`/api/user/${id}`)  // "等"网络返回
  const data = await response.json()                 // "等"解析 JSON
  return data
}
```

### 15.2 关键规则

```
1. await 只能在 async 函数里使用
2. async 函数总是返回 Promise（调用者需要用 await 或 .then() 拿结果）
3. await 不会真的"卡住"整个程序——只是暂停当前函数，其他代码继续跑
```

### 15.3 本项目典型场景

```typescript
// query.ts 中大量使用：
async function* queryLoop(params: QueryParams) {
  while (true) {
    // 调用模型 → 异步等待（同时其他逻辑继续跑）
    for await (const message of deps.callModel({...})) {
      yield message    // 每收到一个 token 就输出
    }
    // 等模型返回完 → 执行工具 → 再循环
  }
}
```

## 十六、生成器 (Generator)

> C 没有这个概念。生成器是一个**可以暂停和恢复**的函数。

### 16.1 同步生成器

```typescript
function* count(): Generator<number> {
  yield 1    // "产出" 1，然后暂停在这里
  yield 2    // 下次被唤醒时从这里继续
  yield 3
}

for (const n of count()) {
  console.log(n)   // 1, 2, 3
}
// 不是一次性返回 [1,2,3]，而是在每个 yield 处停顿
```

### 16.2 异步生成器（本项目核心）

```typescript
async function* streamAIResponse(): AsyncGenerator<string> {
  yield "你好"
  yield "，我是"
  yield "Claude"
}

// 消费：逐个产出，逐个显示
for await (const chunk of streamAIResponse()) {
  process.stdout.write(chunk)
}
// 输出：你好，我是Claude
```

> **这就是聊天中 AI 逐字输出的原理**：
> 模型生成 token → SSE 推送 → `yield` 产出 → `for await` 消费 → 终端立即显示。
>
> 如果不用生成器，必须等整个回复完成才能显示——用户体验极差。

## 十七、模块系统 (Modules)

> 替代 C 的 `#include`，但更安全（有独立作用域，不会污染全局）。

```typescript
// ===== 导出 =====
export function doSomething() { ... }     // 命名导出

if (needHeavyModule) {
  const { hugeFunc } = await import('./heavyModule.js')
  hugeFunc()
}
```

## 十八、错误处理 (Error Handling)

> C 用返回值和 errno，TS 用 try/catch（类似 C++/Java）。

```typescript
try {
  const data = await readFile("config.json")   // 正常逻辑
} catch (error) {
  console.error("读取失败:", error.message)    // 出错时走这里
} finally {
  console.log("无论成功失败都会执行")           // 清理资源（可选）
}

// throw：主动抛出错误
function validate(name: string): void {
  if (!name) throw new Error("名字不能为空")
}
```

## 十九、解构与展开 (Destructuring & Spread)

```typescript
// ===== 对象解构（本项目无处不在）=====
const user = { name: "小明", age: 18, email: "x@y.com" }
const { name, age } = user
// 等价于：const name = user.name; const age = user.age

// ===== 函数参数解构（本项目到处都是）=====
function render({ messages, model, tools }: Config) {
  // 直接用 messages, model, tools，不用写成 config.messages
}

// ===== 数组解构 =====
const [first, second, ...rest] = [1, 2, 3, 4, 5]
// first=1, second=2, rest=[3,4,5]

// ===== 展开运算符 =====
const arr1 = [1, 2]
const arr2 = [...arr1, 3, 4]      // [1, 2, 3, 4]
const obj1 = { a: 1, b: 2 }
const obj2 = { ...obj1, c: 3 }    // { a:1, b:2, c:3 }
```

## 二十、C ↔ TS/JS 速查表

| C 语言 | TS/JS | 备注 |
|--------|-------|------|
| `int` / `float` / `double` | `number` | 不区分整数浮点 |
| `char*` / `char[]` | `string` | 内置字符串类型 |
| `int isDone` (0/1) | `boolean` (`true`/`false`) | 有真正的布尔 |
| `struct { int x; int y; }` | `{ x: number; y: number }` | 对象 / interface |
| `int arr[10]` | `number[]` | 动态扩容 |
| `#include "file.h"` | `import ... from './file'` | 模块导入 |
| `#define MAX 100` | `const MAX = 100` | 常量 |
| `typedef int MyInt` | `type MyInt = number` | 类型别名 |
| `void* ptr` | `any` / `unknown` | 不明确类型 |
| `NULL` | `null` / `undefined` | 两种空值 |
| `printf("%d", n)` | `console.log(n)` | 打印 |
| `malloc()` / `free()` | 自动 GC | 不用管内存 |
| 函数指针 | 箭头函数/回调 | 函数是"一等公民" |
| `for` / `while` / `if` | 完全一样 | — |
| `&` / `&&` | `&` / `&&` | — |
| `enum` | `enum` (支持字符串) | — |
| 无 | `async`/`await` | 异步模型 |
| 无 | Generator `yield` | 可暂停函数 |
| `class` (C++) | `class` | 面向对象 |
