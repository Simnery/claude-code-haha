# 03_09 — 多模态 AI 入门

> Agent 不只处理文本。理解多模态（视觉/语音/视频）为 Agent 打开更多应用场景。

---

## 一、什么是多模态？

| 模态 | 输入方式 | Agent 场景举例 |
|------|---------|--------------|
| **文本** | 自然语言 | 写代码、回答问题 |
| **图像** | 截图/照片 | 看 UI 截图给出修改建议 |
| **语音** | 麦克风 | 语音编程、口述需求 |
| **视频** | 录屏 | 观看用户操作流程，自动生成教程 |
| **文档** | PDF/PPT | 分析合同、总结报告 |

## 二、视觉理解

### API 方案

```python
# Claude Vision API — 分析截图
import anthropic

response = anthropic.messages.create(
    model="claude-sonnet-4-6",
    messages=[{
        "role": "user",
        "content": [
            {"type": "image", "source": {"type": "base64", "media_type": "image/png", "data": base64_image}},
            {"type": "text", "text": "这个页面的登录按钮在什么位置？"}
        ]
    }]
)
```

```python
# GPT-4o Vision — 同样的模式
from openai import OpenAI

response = client.chat.completions.create(
    model="gpt-4o",
    messages=[{
        "role": "user",
        "content": [
            {"type": "image_url", "image_url": {"url": f"data:image/png;base64,{base64_image}"}},
            {"type": "text", "text": "分析这个架构图"}
        ]
    }]
)
```

## 三、语音交互

### 语音 → 文本 (ASR)

```python
# OpenAI Whisper — 语音转文字
from openai import OpenAI

audio_file = open("recording.mp3", "rb")
transcript = client.audio.transcriptions.create(
    model="whisper-1",
    file=audio_file,
    language="zh"
)
print(transcript.text)  # "帮我创建一个用户登录页面"
```

### 文本 → 语音 (TTS)

```python
# 把 Agent 的回复读出来
response = client.audio.speech.create(
    model="tts-1",
    voice="alloy",
    input="好的，我已经创建了登录页面，你可以打开 http://localhost:3000 查看"
)
response.stream_to_file("output.mp3")
```

### 开源方案

| 工具 | 用途 | 特点 |
|------|------|------|
| **Whisper** (OpenAI) | ASR | 开源、多语言、本地可跑 |
| **Faster-Whisper** | ASR | CTranslate2 加速版 |
| **Coqui TTS** | TTS | 开源、多语言 |
| **Bark** (Suno) | TTS | 生成式 TTS，有情感表达 |

## 四、Computer Use — 视觉 Agent 的典型场景

```
Agent 的工作流:
  1. 截屏 (screenshot) → 看当前屏幕
  2. 理解 (vision) → "登录按钮在坐标 (500, 300)"
  3. 行动 (click/type) → 点击坐标 (500, 300)
  4. 再截屏 → 确认操作结果
  5. 循环...
```

本项目 claude code 就内置了 Computer Use 能力（Python Bridge 实现）。

## 五、多模态 RAG

不仅检索文本，也检索图片/表格：

```
文档 (PDF/PPT/网页) 
  ↓ 解析
  ├─ 文本段落 → Embedding → 向量DB
  ├─ 图片说明 → Embedding → 向量DB  
  └─ 表格数据 → 结构化存储 → 关键词索引

用户提问 → 多路检索 → 拼接 → 模型生成
```

### 相关工具

| 工具 | 用途 |
|------|------|
| **Unstructured** | 文档解析 (PDF/PPT/Word → 结构化文本) |
| **LlamaParse** | LlamaIndex 的文档解析器 |
| **ColPali** | 视觉文档检索（直接用图片 Embedding，不先转文字） |
| **Marker** | PDF → Markdown 转换 |

## 六、多模态 Agent 架构

```
┌────────────────────────────────────┐
│         多模态 Agent                │
│                                    │
│  输入层                             │
│  ├─ 文本输入                        │
│  ├─ 图像输入 (截图/照片/图表)        │
│  ├─ 语音输入 (Whisper → 文本)       │
│  └─ 文件输入 (PDF/PPT/Word)         │
│                                    │
│  Agent 核心 (和纯文本 Agent 一样)    │
│  ├─ 推理/规划                       │
│  ├─ 工具调用                        │
│  └─ 记忆                           │
│                                    │
│  输出层                             │
│  ├─ 文本输出                        │
│  ├─ 图像输出 (图表/示意图)           │
│  └─ 语音输出 (TTS)                  │
└────────────────────────────────────┘
```

## 七、关键认知

1. **多模态 API 已成熟** — Claude/GPT-4o/Gemini 都支持图片输入，直接用 API 即可
2. **Computer Use 是视觉 Agent 的典型场景** — 本项目已有实现
3. **文档理解** (PDF/PPT) 是多模态 RAG 的刚需
4. **语音对编程 Agent 不是刚需** — 除非做语音编程/口述需求场景
5. **开源多模态模型在快速追赶** — Qwen-VL, InternVL2 值得关注
