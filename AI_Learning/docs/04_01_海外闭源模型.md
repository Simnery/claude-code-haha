## 一、Anthropic Claude 系列

### 模型矩阵

| 模型 | 定位 | 上下文 | 多模态 | 思考模式 | 输入价格 | 输出价格 |
|------|------|--------|--------|---------|---------|---------|
| **Claude Opus 4.7** | 旗舰，最强推理 | 1M | 是 | ✅ Adaptive | $15/M | $75/M |
| **Claude Sonnet 4.6** | 均衡，日常主力 | 200K | 是 | ✅ Adaptive | $3/M | $15/M |
| **Claude Haiku 4.5** | 快速，简单任务 | 200K | 是 | ❌ | $0.80/M | $4/M |

> 价格单位：$/1M tokens。M = million。

### 各模型特征

**Opus 4.7** — 最复杂的编码/分析/研究任务
- 超强推理链，适合需要"想清楚再说"的场景
- 1M 超长上下文，可一次吞下整个代码库
- 价格是 Sonnet 的 5 倍，只在需要极致质量时用

**Sonnet 4.6** — 编码 Agent 主力
- 99% 场景下的最佳性价比选择
- Claude Code 默认使用 Sonnet 作 base model
- 快模式 (Fast Mode) 可用

**Haiku 4.5** — 低成本、低延迟
- 适合：自动生成标题、简单分类、预处理
- 不适合：复杂推理、大型重构

### 独有特性

| 特性 | 说明 |
|------|------|
| **MCP 协议** | Anthropic 提出并主推，Claude 原生支持 |
| **Thinking Mode** | 模型内部思考链，可配置长度（Opus/Sonnet） |
| **Computer Use** | 原生截图理解 + 坐标操作 |
| **Tool Use** | 并行工具调用、流式工具结果 |
| **Prompt Caching** | 重复 System Prompt 自动缓存，大幅降低成本 |
| **1M Context** | Opus 支持 100 万 token 上下文窗口 |

### API 接入

```bash
# 直连
ANTHROPIC_BASE_URL=https://api.anthropic.com
ANTHROPIC_AUTH_TOKEN=sk-ant-xxx
ANTHROPIC_MODEL=claude-sonnet-4-6

# 或通过 LiteLLM 代理统一接入
ANTHROPIC_BASE_URL=http://localhost:4000
```

## 二、OpenAI GPT 系列

### 模型矩阵

| 模型 | 定位 | 上下文 | 多模态 | 输入价格 | 输出价格 |
|------|------|--------|--------|---------|---------|
| **GPT-4.1** | 旗舰，最强通用 | 1M | 是 | $2/M | $8/M |
| **GPT-4.1 Mini** | 轻量，高性价比 | 1M | 是 | $0.40/M | $1.60/M |
| **GPT-4.1 Nano** | 超轻量，极快 | 128K | 是 | $0.10/M | $0.40/M |
| **o3** | 推理专用，数学/代码 | 200K | 否 | $10/M | $40/M |
| **o4-mini** | 推理轻量 | 200K | 否 | $1.10/M | $4.40/M |
| **GPT-5** | 统一模型 (即将发布) | 400K | 是 | 待定 | 待定 |

### 各模型特征

**GPT-4.1** — 通用旗舰
- 多模态原生支持，代码/写作/分析均衡
- 1M 超长上下文
- 函数调用成熟度最高（Function Calling 生态最完善）

**o3 / o4-mini** — 推理特化
- o 系列 = 内置 Chain-of-Thought，先思考再回答
- 数学证明、复杂逻辑、代码审查这类"需要一步步想"的任务最强
- o3 是 GPT-5 发布前的推理标杆

**GPT-4.1 Mini / Nano** — 降本增效
- Mini: GPT-4o 的 95% 质量，1/5 价格
- Nano: 超低价，适合分类/摘要/简单翻译

### 独有特性

| 特性 | 说明 |
|------|------|
| **Function Calling** | 最早提出，生态最完善 |
| **Structured Outputs** | 强制 JSON Schema 输出（100% 格式正确） |
| **Code Interpreter** | 沙箱 Python 执行 |
| **Assistants API** | 托管 Agent（自带记忆/检索/代码执行） |
| **GPTs / GPT Store** | 可定制的 ChatGPT 分身 |

## 三、Google Gemini 系列

### 模型矩阵

| 模型 | 定位 | 上下文 | 多模态 | 输入价格 | 输出价格 |
|------|------|--------|--------|---------|---------|
| **Gemini 2.5 Pro** | 旗舰 | 1M | 是 | $1.25/M | $10/M |
| **Gemini 2.5 Flash** | 快速 | 1M | 是 | $0.15/M | $0.60/M |
| **Gemini 2.5 Flash-Lite** | 极速 | 1M | 是 | $0.075/M | $0.30/M |

### 各模型特征

**Gemini 2.5 Pro** — 最强长上下文
- 原生 1M 上下文（实测可用，不是硬塞的）
- 多模态原生（图/视频/音频/PDF 一起输入）
- Google 生态整合（Vertex AI / BigQuery / Google Search）

**Gemini 2.5 Flash** — Cursor 默认模型
- 速度快，价格低，适合高频调用的 Agent
- Cursor Agent Mode 默认使用此模型

**Flash-Lite** — 极低成本
- 100万 token 输出只要 $0.30，适合大规模批量任务

### 独有特性

| 特性 | 说明 |
|------|------|
| **长上下文标杆** | 1M 上下文实测效果最佳 |
| **多模态原生** | 视频/音频/PDF 不用预处理 |
| **Google Search Grounding** | 搜索结果直接注入回答 |
| **Vertex AI** | 企业级部署平台 |
| **A2A 协议** | Google 提出的 Agent 间通信协议 |
