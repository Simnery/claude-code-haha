## 三、部署方式选型

```
                    ┌──────────────┐
                    │  你的情况？   │
                    └──────┬───────┘
           ┌───────────────┼───────────────┐

      │ 最简单   │    │+ 多模型 │    │ vLLM +  │
      │ 按量付费 │    │降本30%+ │    │ GPU 集群 │
      └─────────┘    └─────────┘    └─────────┘
```

### 各方案详解

**方案 A: 直接 API（推荐起步）**
```
适用: 日调用 < 1000 次、原型验证、个人项目
实施: 注册 API Key → 配 .env → 用上
优点: 零运维、永远用最新模型
缺点: 成本随用量线性增长
```

**方案 B: LiteLLM 多模型路由**
```
适用: 日调用 1K-10K 次、有多种任务类型
实施:
  1. 部署 LiteLLM (docker 一行命令)
  2. 配置路由规则 (简单任务 → 便宜模型, 复杂 → 强模型)
  3. Agent 统一调 LiteLLM 端点
优点: 灵活、降本、不绑定单一供应商
```

**方案 C: 自部署开源模型**
```
适用: 日调用 >10K 次、数据合规要求、已有机房
实施:
  1. 选择开源模型 (Qwen-Coder / DeepSeek)
  2. 部署 vLLM / Ollama
  3. LiteLLM 统一网关
  4. 监控 + 告警
```

## 四、成本估算公式

### API 成本

```
月成本 = 日调用次数 × 平均输入token × 输入单价
       + 日调用次数 × 平均输出token × 输出单价
       × 30

示例 (编码 Agent, Claude Sonnet):
  日 200 次调用
  平均输入: 10,000 tokens (代码上下文)
  平均输出: 2,000 tokens (生成代码)
  
  日成本 = 200 × (10K × $3/M + 2K × $15/M)
         = 200 × ($0.03 + $0.03)
         = $12/天
  月成本 ≈ $360
```

### 自部署成本

```
月成本 = GPU 租赁/摊销 + 电力 + 运维人力

示例 (1×A100 80G, 云租用):
  GPU: ¥12,000/月
  带宽: ¥500/月
  运维: ¥3,000/月 (兼职)
  合计: ¥15,500/月

需要日调用 > 3,000 次才能和 API 打平。
```

## 五、风险与备份

### 单点故障风险

```
❌ 只接一个模型 API → 挂了就全挂了
✅ 至少两个后备方案:

主: Claude Sonnet 4.6 (Anthropic API)
备1: GPT-4.1 (OpenAI API) — 不同供应商
备2: DeepSeek-V4-Pro — 不同国家/价格层
```

### 成本失控防护

```python
# LiteLLM 配置月度预算上限
litellm_settings:
  max_budget: 500  # $500/月
  budget_duration: 1mo

# 各模型单独限流
model_list:
  - model_name: claude-sonnet-4-6
    litellm_params:
      rpm: 50        # 每分钟最多 50 次
      tpm: 100000    # 每分钟最多 10 万 token
```

## 六、最终推荐

### 个人开发者 / 学习阶段

```
推荐: Claude Sonnet 4.6 (API) + DeepSeek-V4-Pro (备用)
理由: Sonnet 编码最强，DeepSeek 超便宜做补充
月预算: $50-200
```

### 小团队 / 创业公司

```
推荐: DeepSeek-V4-Pro (主力) + Claude Sonnet (复杂任务)
     + LiteLLM 路由
理由: 国内最便宜、质量够用、关键任务用 Claude
月预算: ¥500-3,000
```

### 企业级

```
推荐: 混合架构
  - 主力: 自部署 Qwen2.5-Coder-32B (vLLM + A100)
  - 复杂: Claude Sonnet API
  - 简单: DeepSeek-V4-Flash API
  - 网关: LiteLLM 统一路由 + 监控
月预算: ¥15K-50K (含 GPU)
```
