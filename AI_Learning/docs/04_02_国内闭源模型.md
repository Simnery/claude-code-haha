## 一、DeepSeek

### 模型矩阵

| 模型 | 定位 | 上下文 | 开源 | 输入价格 | 输出价格 |
|------|------|--------|:---:|---------|---------|
| **DeepSeek-V4-Pro** | 旗舰，推理+编码 | 1M | ❌ | ¥1/M | ¥4/M |
| **DeepSeek-V4-Flash** | 快速 | 1M | ❌ | ¥0.25/M | ¥1/M |
| **DeepSeek-R1** | 推理特化 (MoE) | 128K | ✅ MIT | ¥4/M | ¥16/M |

> 价格单位：¥/1M tokens。国内价格普遍是海外的 1/5 ~ 1/10。

### 各模型特征

**DeepSeek-V4-Pro** — 当前运行本项目的模型
- 1M 上下文，编码和逻辑强
- MoE 架构（671B 总参数，37B 激活），推理成本低
- API 完全兼容 Anthropic 接口格式

**DeepSeek-V4-Flash** — 低成本
- 适合：批量处理、简单任务、高频 Agent 调用

**DeepSeek-R1** — 推理王者
- 内置超长 CoT（Chain-of-Thought），数学/代码能力顶尖
- 不适合：需要快速响应的场景（推理 token 不可控）

### 独有特性

| 特性 | 说明 |
|------|------|
| **开源文化** | 技术报告详尽，开源模型权重 |
| **API 兼容** | 兼容 Anthropic Messages API 格式 |
| **超低价格** | 约为 Claude Sonnet 的 1/10 |
| **国产合规** | 数据不出境，适合国内企业 |
