---

## 一、外部适配器 (`adapters/`)

独立的 TypeScript 子项目，提供外部平台对接：

### IM 适配器
- 消息平台集成 (Slack / Discord 等)
- 消息格式双向转换
- 认证与 token 管理
- WebSocket 长连接维护

### 通信模式
```
外部平台消息 → Adapter → CLI 标准输入
CLI 标准输出 → Adapter → 外部平台回复
```

## 二、技能系统 (`src/skills/`)

### 技能定义
```typescript
interface Skill {
  name: string           // 技能名
  description: string    // 描述
  prompt: string        // 注入到 system prompt 的内容
  when: string[]        // 触发条件 (关键词匹配)
}
```

### 内置技能 (`bundled/`)
- 项目自带的基础技能
- 自动加载

### 用户技能
- `~/.claude/skills/` — 用户级
- `.claude/skills/` — 项目级
- 通过 SkillTool 调用

### 技能发现
- `skillChangeDetector.ts` — 检测技能文件变更
- `EXPERIMENTAL_SKILL_SEARCH` — AI 驱动的技能匹配

## 三、记忆系统 (`src/memdir/`)

### MEMORY.md
- `~/.claude/projects/<hash>/MEMORY.md` — 自动记忆
- `.claude/memory/` — 手动管理的记忆文件
- 加载时机：每次对话开始
- 记忆类型：user / feedback / project / reference

### 自动记忆 (Auto Memory)
- `CLAUDE_CODE_DISABLE_AUTO_MEMORY` — 禁用
- 模型自动判断是否需要记录
- 写入 MEMORY.md 文件

## 四、Hooks 系统 (`src/hooks/`)

### Hook 事件类型
```
PreToolUse        → 工具执行前
PostToolUse       → 工具执行后
Notification      → 通知事件
UserPromptSubmit  → 用户提交前
SessionStart      → 会话开始
SessionEnd        → 会话结束
Stop              → 停止
```

### Hook 注册
- SDK 回调: `registerHookCallbacks()`
- 插件 Hooks: plugin 声明
- 执行优先级: SDK > Plugin

## 六、持久化层 (`src/utils/sessionStorage.ts`)

### Transcript 格式 (JSONL)
```
{"type":"user","message":{"role":"user","content":[...]}}
{"type":"assistant","message":{"role":"assistant","content":[...]}}
{"type":"tool_use","tool_name":"Read","tool_input":{...}}
{"type":"tool_result","content":"..."}
```

### 存储路径
```
~/.claude/
  ├── projects/
  │   └── <cwd-hash>/
  │       ├── <sessionId>.jsonl    ← 会话 transcript
  │       └── MEMORY.md            ← 项目记忆
  ├── settings.json                ← 用户全局设置
  ├── credentials/                 ← OAuth tokens
  └── sessions/                    ← PID 文件等
```

### 会话恢复
- `/resume <sessionId>` — 恢复特定会话
- `-c` / `--continue` — 继续最新会话
- 恢复时重建: messages, fileState, cost 状态

## 九、输入处理 (`src/utils/processUserInput/`)

### `processUserInput()`
```
用户文本输入
  ↓
解析 /command → 执行命令逻辑
解析 @mention → 文件/Agent 引用
添加附件 (image/file)
添加 CLAUDE.md 内容
添加 memory 内容
添加上下文 suggestion
  ↓
构建 Message[] → 传给 query()
```
