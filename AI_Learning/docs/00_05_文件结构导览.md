## 二、核心文件（按重要性排序）

| 文件 | 行数 | 作用 |
|------|------|------|
| `src/entrypoints/cli.tsx` | ~300 | **终端入口**。解析命令行参数，找到对应的功能去执行 |

## 三、阅读路线推荐

### 路线 1：快速概览（2 小时）

```
cli.tsx（入口，短）→ main.tsx（只看前 100 行 + Commander 参数部分）
→ query.ts（看函数签名 + 注释，不读实现）
→ Tool.ts（看接口定义）
→ commands.ts（看注册表）
```

### 路线 2：追踪一个请求（4 小时）

```
用户输入 "帮我读 README.md"
  → REPL.tsx TextInput onChange
  → processUserInput.ts
  → query.ts while(true)
  → claude.ts API 调用
  → query.ts 收到 assistant（有 tool_use: Read）
  → toolOrchestration.ts → FileReadTool 执行
  → query.ts 收到 tool_result → 继续 while(true)
  → claude.ts API 调用（最终回复）
  → REPL.tsx 渲染
```

### 路线 3：追踪 /model 命令（1 小时）

```
用户输入 "/model opus"
  → commands.ts 路由
  → commands/model/model.tsx SetModelAndClose
  → model.ts parseUserSpecifiedModel("opus")
  → modelStrings.ts 获取模型 ID
  → state.ts setMainLoopModelOverride()
  → 下一次 query() 用新模型
```

## 四、文件命名约定

| 约定 | 示例 | 说明 |
|------|------|------|
| `.ts` | `query.ts`, `model.ts` | 纯逻辑代码 |
| `.tsx` | `REPL.tsx`, `App.tsx` | 含 JSX 的 UI 代码 |
| `index.ts` | `commands/model/index.ts` | 模块入口 |
| `types.ts` | `types/message.ts` | 类型定义集中 |
| `utils.ts` | `utils/messages.ts` | 辅助函数 |
| `test.ts` | `stopHooks.test.ts` | 测试文件 |
