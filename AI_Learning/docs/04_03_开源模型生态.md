## 一、为什么关注开源模型？

| 场景 | 闭源 API | 开源自部署 |
|------|---------|-----------|
| 成本 (低频) | ✅ 便宜 | ❌ GPU 成本高 |
| 成本 (高频) | ❌ 贵 | ✅ 摊薄后更便宜 |
| 数据隐私 | ⚠️ 需信任 | ✅ 完全可控 |
| 定制能力 | ❌ 只能调 Prompt | ✅ 可微调 |
| 可用性 | ⚠️ 依赖服务商 | ✅ 自己控制 |
| 离线使用 | ❌ 不行 | ✅ 可以 |

## 七、开源模型部署工具链

```
模型选择
  ↓
量化 (llama.cpp / AWQ / GPTQ)
  ↓
推理引擎 (Ollama 开发 / vLLM 生产)
  ↓
API 网关 (LiteLLM / OpenRouter)
  ↓
Agent 应用
```

### 常用量化工具

| 工具 | 输出格式 | 适用 |
|------|---------|------|
| **llama.cpp** | GGUF | 消费级硬件、Ollama 后端 |
| **AutoGPTQ** | GPTQ | GPU 推理 |
| **AutoAWQ** | AWQ | GPU 推理（比 GPTQ 质量略好）|

### 微调框架

| 框架 | 特点 |
|------|------|
| **LLaMA-Factory** | 最简单、Web UI、支持上百种模型 |
| **Unsloth** | 速度最快 (2-5x)、显存最省 (50-70%↓) |
| **Axolotl** | 最灵活、配置文件驱动 |
| **HuggingFace TRL** | 官方、SFT/DPO/RLHF 全覆盖 |
