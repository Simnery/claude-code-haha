# 06 — 服务端与 API

> 覆盖文件：`src/services/`, `src/server/`

---

## 一、API 调用层 (`src/services/api/`)

### Claude API 客户端 (`claude.ts`)
- 封装 Anthropic Messages API 调用
- 处理 streaming/non-streaming 响应
- token usage 追踪 + 累加 (`accumulateUsage`)
- 错误分类 (`errors.ts`): 可重试/不可重试/限流/鉴权
- fallback 模型支持
- fast mode header 注入

### 请求构建
```
messages + systemPrompt + thinkingConfig + tools
  → prependUserContext / appendSystemContext
  → Anthropic SDK Beta Message Create
  → SSE Stream → 逐块 yield
```

### 错误处理 (`errors.ts`)
```typescript
categorizeRetryableAPIError(error) → {
  retryable: boolean,       // 是否可重试
  reason: string,           // 错误原因
  businessErrorCode: string // 业务错误码
}
```

### 重试机制 (`withRetry.ts`)
- 指数退避重试
- 最大重试次数限制
- FallbackTriggeredError → 触发 fallback 模型

## 二、MCP 协议层 (`src/services/mcp/`)

### MCP 客户端 (`client.ts`)
- 管理 MCP 服务器连接生命周期
- 发现 tools/resources/prompts
- 工具调用路由
- 连接状态追踪

### MCP 配置 (`config.ts`)
- 从 `.claude/.mcp.json` 读取配置
- 支持 stdio / sse / streamable 传输
- Enterprise MCP 配置合并
- Claude.ai MCP 订阅 (`claudeai.ts`)

### MCP 类型 (`types.ts`)
```typescript
McpServerConfig = {
  type: 'stdio' | 'sse' | 'streamable'
  command?: string
  args?: string[]
  url?: string
  headers?: Record<string, string>
  env?: Record<string, string>
}
```

### Official MCP Registry (`officialRegistry.ts`)
- 预取官方 MCP 服务器 URL 列表
- 验证服务器可用性

## 三、OAuth 认证 (`src/services/oauth/`)

### 流程
```
1. 用户触发 login
2. 打开浏览器 → 授权页面
3. 本地回调服务器接收 code
4. 交换 access_token / refresh_token
5. 存储到 keychain (macOS) / 文件 (其他平台)
```

### 核心文件
- `client.ts` — OAuth 客户端逻辑
- `accountInfo.ts` — 账户信息管理
- 支持 Console OAuth Flow (非交互模式下在终端完成)

## 四、会话管理 (`src/services/`)

### 会话存储 (`src/utils/sessionStorage.ts`)
- JSONL 格式持久化: `~/.claude/projects/<hash>/<sessionId>.jsonl`
- 每行一个事件: user message / assistant message / tool use / tool result
- 支持会话恢复: `/resume <id>` / `--continue`
- 支持搜索: 按自定义标题查找

### 会话恢复 (`conversationRecovery.ts`)
- 检测未正常关闭的会话
- 自动恢复选项
- 对话恢复时的状态重建

### 并发会话 (`concurrentSessions.ts`)
- PID 文件追踪活跃会话
- 防止重复启动同一会话

## 七、远程管理设置 (`src/services/remoteManagedSettings/`)

### MDM (Mobile Device Management) 集成
- macOS: plist 读取
- Windows: 注册表读取
- 企业统一配置下发

### 设置源优先级

| 优先级 | 来源 | 说明 |
|--------|------|------|
| 1 | policySettings | 组织策略 (最高) |
| 2 | flagSettings | CLI flag 临时设置 |
| 3 | localSettings | `.claude/settings.local.json` |
| 4 | projectSettings | `.claude/settings.json` (项目级) |
| 5 | userSettings | `~/.claude/settings.json` (用户级) |

## 八、插件系统 (`src/services/plugins/`, `src/plugins/`)

### 插件类型
- **Bundled plugins** — 内置插件 (bundled/)
- **Marketplace plugins** — 从 marketplace 安装

```
install → load → enable → (hooks/mcp/tools) → disable → uninstall
```

### 插件能力

- 注册 Hooks
- 注册自定义命令
- 注册自定义工具
