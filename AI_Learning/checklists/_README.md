# checklists/ — 学习进度清单

## 用途

跟踪学习进度，避免"不知道接下来学什么"。

## 使用方式

- 每开始一项，标记为 🟡
- 每完成一项，标记为 ✅ 并写上日期
- 定期回顾，看还有什么没做

## 建议清单

### 语法清单

```
checklists/
├── 01_TS语法清单.md        ← 对照 00_01_TS语法教程.md 的 20 节
├── 02_架构阅读清单.md      ← 对照 01_01~01_09 架构文档
└── 03_源码阅读清单.md      ← 对照 00_05_文件结构导览.md
```

### 清单模板

```markdown
# {清单名称}

> 创建日期：{日期}
> 最后更新：{日期}

## 进度

| 序号 | 内容 | 状态 | 完成日期 | 笔记 |
|------|------|------|---------|------|
| 1 | 关键字 | ✅ | 06-03 | |
| 2 | 基本数据类型 | ✅ | 06-03 | |
| 3 | 变量声明 | 🟡 | | |
| 4 | 运算符 | ⬜ | | |
| ... | ... | ... | ... | |

图例：✅ 完成  🟡 进行中  ⬜ 未开始  ⏸️ 暂停
```
