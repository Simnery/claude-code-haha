# notes/ — 学习笔记

## 用途

阅读 `docs/` 中的教程、追踪源码时的个人理解和疑问记录。

## 使用方式

- 每读完一个概念或一个文件，写一篇笔记
- 格式自由，重点是 **自己的话复述**（死记硬背没用，能讲出来才算懂）
- 遇到不懂的术语/语法，先记下来，后续查 `docs/` 或问我

## 建议文件命名

```
notes/
├── 2026-06-03_闭包理解.md          ← 日期 + 主题
├── 2026-06-04_query循环初读.md
├── 2026-06-05_模型选择优先级.md
└── questions.md                     ← 汇总所有不懂的问题
```

## 示例

```markdown
# 闭包：函数"记住"了外部变量

> 日期：2026-06-03
> 来源：00_01_TS语法教程.md 第 8.5 节

## 核心理解
普通函数执行完，内部变量就销毁了（和 C 一样）。
但如果函数 A 内部返回了函数 B，B 引用了 A 的变量，
JS 引擎就不会回收这些变量——B "封闭并保留"了 A 的作用域。

## 关键代码
function makeCounter() {
  let count = 0
  return () => ++count  // 这个箭头函数抓住了 count
}
const c = makeCounter()
c() // 1
c() // 2 ← count 没被销毁

## 和已有知识的联系
C 语言的 static 局部变量可以实现类似效果（值跨调用保持），
但 static 是全局唯一的，闭包每次调用都创建一个独立副本。
这个在项目的 AgentTool 里大量使用——每个子 Agent 有自己独立的状态。

## 还不懂的地方
- [ ] 闭包会不会导致内存泄漏？什么时候该手动清理？
```
